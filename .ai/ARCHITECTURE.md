# Architecture

The site is a lightweight static GitHub Pages site using semantic HTML, CSS, vanilla JavaScript, and JSON. Do not add an unnecessary framework, trackers, external fonts, or a heavy dependency system without explicit need.

Never invent church facts. The giving page must not collect or store card or bank information, and any external giving destination must be verified before publication. Compatibility routes and retired-route safeguards are material. Production domain and indexing state are release-sensitive. A production launch is distinct from a source merge.
