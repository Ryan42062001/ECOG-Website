# Persistent decisions

- Repository evidence outranks chat memory.
- Public-facing facts must be verified; do not invent church information to fill gaps.
- `main` is the stable reviewed source.
- Production domain and indexing require explicit launch authorization.
- CNAME, DNS, and Pages custom-domain changes are release actions.
- Giving/payment surfaces remain external and verified.
- Old PR acceptance does not automatically authorize integration.
- Production merge and DNS cutover are separate decisions.
- Rollback must be planned before production cutover.
