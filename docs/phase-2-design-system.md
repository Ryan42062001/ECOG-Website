# Phase 2 — Modern UI & Design System

Starting checkpoint: `49c5552479dd46dfce8f3455a054e70447913f3e`

## Approved brand direction

Phase 2 modernizes the existing ECOG identity rather than replacing it.

Retain:
- Circular church mark
- Cross as the primary symbol
- Cyan/electric-blue identity
- Deep dark background
- White ECOG lettering

Simplify:
- Remove water/flame texture from the redesigned production mark
- Remove heavy glow, bevel, and metallic effects
- Use clean geometry and typography
- Ensure the identity works at favicon, mobile-header, social, print, and signage sizes

The uploaded legacy logo remains the source identity. The generated redesign board is concept/reference material only and must not be treated as the final production logo asset.

## Visual direction

ECOG should feel modern, warm, local, welcoming, energetic, and distinctly Christian without imitating a megachurch or corporate nonprofit aesthetic.

Primary visual language:
- Deep navy / charcoal foundations
- Bright cyan primary accent
- White and cool off-white surfaces
- Restrained blue supporting tones
- Strong typographic hierarchy
- Generous spacing
- Authentic church photography when verified assets are supplied
- Subtle motion only where it improves comprehension

## Phase 2 token foundation

The initial token system establishes:
- brand colors and accessible darker accent variants
- surface and border colors
- shadows
- radii
- spacing primitives
- container width
- typography family hook
- focus-visible treatment

Phase 2B may refine exact values as components are tested, but changes should remain token-driven.

## Component direction

Shared components should support:
- responsive site header/navigation
- circular ECOG brand mark
- primary, secondary, and outline buttons
- page and homepage heroes
- service-information strip
- section headings and eyebrow labels
- cards and media cards
- split content/media sections
- calls to action
- footer
- accessible keyboard focus and reduced-motion behavior

## Content and launch safety

Phase 2 is visual-system work. It must not:
- connect the production domain
- add a production `CNAME`
- enable indexing
- invent pastor, event, sermon, or ministry details
- add unapproved giving/payment integrations

Real photography, final production logo files, verified church content, live sermon/event data, SEO launch settings, and production DNS remain later-phase work.
